# What logs in where

Which login methods dodo's agent gets through, on your Mac (dodo's Chrome window) and remotely (headless Chromium in Cloud Run). The measured part below is written by `pnpm test:auth` ([AUTH_TESTING.md](AUTH_TESTING.md)); the expectations are what the code and earlier debugging say, until a run confirms or corrects them.

## Expected (from the code, not yet measured)

| Method                         | Local (Mac)                                                                                                                                                                                                                                                                                               | Remote (cloud)                                                                                                                                                                                                                                                                                                                              |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| itsme (engie.be)               | Works, with you at the Mac: itsme shows a QR code that changes every few seconds, so the agent brings the login to the front in the dodo Chrome window and asks you to scan it there with the app (no picture is sent). A site that still offers the phone-number option sends a push to the app instead. | Not here: nobody can scan a QR code that changes every few seconds in the cloud browser, so the agent calls `request_device` as soon as itsme comes up and the task continues on the Mac (at once with Device = Auto; after a yes on the card when pinned to Remote). Expected result: works after moving.                                  |
| Google (vinted)                | Works in the real Chrome window via "Continue with Google"; the 2-step prompt goes to your phone. You are needed at the Mac when Google offers a passkey, Touch ID or a security key, or shows a CAPTCHA.                                                                                                 | Uncertain. Google often refuses automated or data-centre browsers ("This browser or app may not be secure"). When it does, the agent calls `request_device` and the fallback takes the task to your Mac. Once signed in anywhere remotely, your stored Google session (`use_google_session`) serves later remote tasks without a new login. |
| Username + password (overleaf) | Works: the agent types from the vault. Overleaf may show a CAPTCHA, which then needs you at the Mac.                                                                                                                                                                                                      | Works unless Overleaf's bot check refuses the cloud browser; then the fallback takes it to the Mac.                                                                                                                                                                                                                                         |
| Email + 2FA (booking.com)      | Works: the agent enters your email address (personal info, or the vault entry if you have one). Emailed codes are fetched from Gmail (`get_email_code`); SMS codes and authenticator codes are asked as secret answers (TOTP from the vault is not built yet).                                            | Same, unless the site's bot protection (a CAPTCHA wall, a "suspicious login" block) refuses the cloud browser's address; then the fallback takes it to the Mac.                                                                                                                                                                             |

Where a login needs you at the Mac rather than on your phone, see [AUTH_TESTING.md](AUTH_TESTING.md#when-you-have-to-be-at-the-mac).
